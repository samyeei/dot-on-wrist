# Ask an agent to install Dot on Wrist

Copy this prompt into an agent that can operate your Mac. Open your own Dot conversation in Chrome first.

> Set up Dot on Wrist from https://github.com/samyeei/dot-on-wrist on this Mac. Read docs/INSTALL.md and inspect the existing setup first. Ask me whether I want M5Stack StopWatch, Apple Watch, or both if that is not already clear. Reuse compatible dependencies and install missing ones, create the Python environment, and run the repository's local configuration and gateway scripts. Use my own Dot conversation URL through the hidden prompt. Help load the Chrome extension and confirm its badge is ON. For M5Stack, confirm the model and USB port, create and verify a local full-flash backup, build the firmware and flash the correct device. For Apple Watch, help me use my Xcode development team, sign the app, and install it on my paired watch. Pause for actions that require me to sign in, grant macOS permissions, use Developer Mode, or put the hardware into download mode. Verify the connection, one short voice reply, and live-call hangup. Report what was actually verified. Keep conversation URLs, tokens, TLS keys, backups, and paired binaries local.
