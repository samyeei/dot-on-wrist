# v0.1.0

First public source release of Dot on Wrist.

- M5Stack StopWatch firmware source for USB installation with PlatformIO.
- Chrome extension source and an unpacked extension ZIP for macOS.
- Native watchOS source for personal signing and installation through Xcode.
- Local Mac gateway, pairing setup, project artwork, and installation instructions in English, Simplified Chinese, and Japanese.

Build device binaries locally with your own pairing credentials. The extension ZIP is distributed through GitHub for Chrome's Load unpacked workflow.
